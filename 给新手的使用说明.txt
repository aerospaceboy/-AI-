Video → AI 资料包 · Windows 新手版
================================

1. 先把整个 Video2AI 文件夹解压到电脑上。不要只单独拖出 exe。
2. 双击 Video2AI.exe。
3. 点“选择视频…”，第一次建议选一个 1–3 分钟的 MP4 视频。
4. 保持默认的 base 语音模型，点“开始生成”。模型已经包含在文件夹内，断网也能处理；长视频在 CPU 上可能需要较长时间。
5. 显示“完成”后，点“查看网页报告”阅读内容；点“打开上传包目录”，把其中的 upload_bundle.zip 发给 ChatGPT。

这个入门版使用 CPU，电脑没有 NVIDIA 显卡也能运行。处理在你的电脑上完成，不会把视频上传到服务器。若主动切换 tiny 或 small 模型，首次使用该模型时才需要联网下载。

输出默认在原视频旁边，文件夹名称是在视频文件名后加 _ai。再次处理同一个视频会复用已有结果。

如果软件没有打开，先确认整个文件夹已解压。Windows 若显示来源未知提示，请确认文件来自你信任的朋友；这个便携版没有代码签名。

可选：AI 自动总结与 AI 看图（联网）
在软件文件夹里新建一个文本文件，命名为 OPENAI_API_KEY.txt，把阿里云百炼等服务的 API Key 粘贴进去并保存，然后重新打开软件——"AI 总结"和"AI 看图"会自动勾上，点"开始生成"即可。也可以直接点界面上的"密钥设置…"粘贴密钥。"AI 总结"只发送语音字幕和屏幕文字；"AI 看图"会把关键帧截图发给视觉模型生成画面描述。视频本身不会上传。没有 Key 时保持不勾选，软件照常生成基础资料包。
注意：不要把包含 OPENAI_API_KEY.txt 或 .env 的文件夹发给其他人。
